About This Website

The Appliance Energy Consumption Website is an educational website designed to demonstrate fundamental web development concepts.

The website contains information about appliance energy consumption and provides users with a simple way to explore information about household televisions.

Purpose

The purpose of this website is to demonstrate the use of HTML to structure webpages, CSS to create a consistent visual design and JavaScript to provide basic interactive functionality.

Website Structure

The website contains three pages: Home, Televisions and About Us. A consistent navigation menu allows users to move between all three pages.

Technologies Used

HTML is used to define the content and structure of each webpage.

CSS is used to control the colours, spacing, navigation, layout, hover effects and overall appearance of the website.

JavaScript is used on the Home page to provide interactive FAQ accordion functionality.
